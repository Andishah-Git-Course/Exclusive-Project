# 🛍️ Exclusive

A responsive e-commerce website built with **HTML and CSS** as a front-end practice project.

The goal of this project was to practice building a multi-page website, creating responsive layouts, and working with **Flexbox, CSS Grid, Media Queries, and reusable UI structures**.

## 🌐 Live Demo

[View Live Website](https://andishah-git-course.github.io/Exclusive-Project/)

## 📸 About the Project

**Exclusive** is a multi-page e-commerce-style website inspired by modern online shopping interfaces.

The project includes different pages for authentication, account management, shopping cart, checkout, and contact information.

## 📄 Pages

* 🏠 Home
* 📖 About
* 📞 Contact
* 🔐 Login
* 📝 Sign Up
* 👤 Account
* 🛒 Cart
* ❤️ Wishlist
* 💳 Checkout

## 🛠️ Technologies

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Font Awesome

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

The responsive layout adapts the navigation, forms, cards, images, content sections, and footer to smaller screens.

## 🚀 Getting Started

Clone the repository:

```bash

```

Open the project folder:

```bash
cd Exclusive-Project
```

Then open `index.html` in your browser.

You can also use **Live Server** in Visual Studio Code during development.
